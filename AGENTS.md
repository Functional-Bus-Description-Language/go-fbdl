# Code formatting
- Functions occupying more than one line of code shall have one empty line before and after the function.

# Testing and linting
- Always run `make test-all` after the work is done to make sure all tests pass.
- Always run `make lint` after the work is done to make sure there are no linting errors.

# Tests
- Prefer simple, explicit structure of test functions.
- If possible, and test cases to existing test functions instead of adding new ones.
